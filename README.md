# cllo — پلتفرم یادگیری زبان انگلیسی با متد C. K. Ogden

پروژه وب‌اپلیکیشن یادگیری زبان انگلیسی بر اساس روش ۸۵۰ لغت پایه چارلز کی آگدن (**C. K. Ogden**)، همراه با تمرین‌های تعاملی ۴ گانه، تلفظ صوتی، سیستم اشتراک سوپابیس (Supabase) و طراحی اختصاصی واکنش‌گرا برای موبایل و دسکتاپ.

---

## 🚀 نحوه اجرا روی سیستم شخصی یا سرور

این پروژه یک وب‌اپلیکیشن استاندارد **React 19 + TypeScript + Vite + Tailwind CSS** است.

### مراحل اجرا:
1. ابتدا مطمئن شوید [Node.js](https://nodejs.org) (نسخه 18 به بالا) روی سیستمتان نصب است.
2. پروژه را باز کرده و در ترمینال دستور زیر را اجرا کنید تا تمام پیش‌نیازها نصب شوند:
   ```bash
   npm install
   ```
3. اجرای پروژه در حالت توسعه (Development):
   ```bash
   npm run dev
   ```
   برنامه روی آدرس `http://localhost:3000` اجرا خواهد شد و دقیقاً مشابه همین محیط کار می‌کند.

4. ساخت نسخه نهایی جهت انتشار روی هاست یا گیت‌هاب پیجز (Production):
   ```bash
   npm run build
   ```
   فایل‌های نهایی و بهینه‌شده در پوشه `dist` ایجاد می‌شوند و می‌توانید آن را روی هر هاست، Vercel، Netlify یا سرور دلخواه آپلود کنید.

## 📁 ساختار پوشه‌های پروژه در گیت‌هاب (Folder Structure)

```text
├── src/
│   ├── components/       # تمام کامپوننت‌های رابط کاربری (کارت‌ها، اسلایدرها، مودال‌ها، هدر)
│   ├── data/             # دیتای ۱۰۰ لغت کلاس اول و تمرین‌های ۴گانه
│   ├── utils/            # توابع صوتی، اتصال به Supabase و خروجی ZIP/HTML
│   ├── App.tsx           # کامپوننت و مدیریت وضعیت اصلی برنامه
│   ├── main.tsx          # نقطه ورود React
│   └── index.css         # استایل‌های سراسری، فونت وزیرمتن و قوانین موبایل
├── public/               # فایل‌های مستقل و دانلودی (cllo_app_html.zip و cllo_ogden_app.html)
├── package.json          # پکیج‌ها و اسکریپت‌های پروژه
├── tsconfig.json         # تنظیمات TypeScript
├── vite.config.ts        # تنظیمات سرور و پلاگین‌های Vite
└── README.md             # راهنمای پروژه
```

## 🌟 ویژگی‌های پیاده‌سازی شده:
- **۱۰۰ لغت متد آگدن (کلاس ۱: مقدماتی)** همراه با فونتیک و معنی دقیق فارسی.
- **۴ تمرین تعاملی**: جمله‌سازی، سؤال و جواب، داستان کوتاه، و مکالمه دونفره.
- **تشخیص خودکار زبان در فیلدهای متنی**: متن فارسی خودکار راست‌به‌چپ (RTL) و انگلیسی خودکار چپ‌به‌راست (LTR).
- **قفل عدم زوم در موبایل و سافاری**: جلوگیری از لرزش و زوم ناخواسته در مرورگرهای گوشی.
- **اسکرول خودکار نرم ۱۶۰ پیکسل**: بعد از ۲ ثانیه از زدن «لغت بعدی»، صفحه ۱۶۰ پیکسل به سمت پایین حرکت کرده و تمرین را در دید قرار می‌دهد (بدون اسکرول اضافه در انتهای صفحه).
- **قفل اشتراک و حساب کاربری**: ۱۰ لغت اول رایگان؛ سپس درخواست کد ۵ رقمی اشتراک و اتصال به Supabase.
- **دانلود پکیج مستقل ZIP**: امکان خروجی گرفتن و دانلود مستقیم بسته تک‌صفحه‌ای در هر لحظه.
